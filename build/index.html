Verifiable Intent · Credential Anatomy

Delegation Chain — Field Visibility

Each layer cryptographically binds the next via cnf.jwk. Fields are either always visible or selectively disclosable.

Signature & Binding Summary
L1 signed by Credential Provider key · cnf.jwk = User Pub Key
L2 signed by User key (from L1 cnf) · sd_hash binds → L1 · mandate cnf.jwk = Agent Pub Key
L3 signed by Agent key (from L2 mandate cnf) · sd_hash binds → L2 · no cnf (terminal)
Signature & Binding Summary
L1 signed by Credential Provider key · cnf.jwk = User Pub Key
L2 signed by User key (from L1 cnf) · sd_hash binds → L1 · no cnf — chain terminates
